# Smart Scan POS

A separate supermarket point-of-sale project for Android-first use, with Urdu and English interface, barcode scanning, inventory, billing, receipts, and an owner dashboard.

## Current stage

The first commit establishes the responsive POS interface and local demo workflow. It is not yet a production APK. Camera scanning, secure owner/operator accounts, cloud sync, thermal printer support, and Android packaging will be added and tested in later stages.

## Privacy

Do not add real customer records, passwords, API keys, or production sales data to this repository.
